Bookmark Manager#
1.project Title
Bookmark manager-Web-Based Bookmark Management system

2.Project Description
The Bookmark manager is a simple web application development using HTML,CSS, and JavaScript.it allows users to save their
favorite website be entering a bookmark name and URL.

the application displays saved bookmarks with three main actions

Visit- opens the saved website

Remove- deletes the bookmark from the list.

Add Bookmark - adds new a website to the bookmark list.

3. technologies Used

. HTML- created the structure of the apllication. 
.CSS- designed the layout, colors, buttons , cards, and responsive interface,
.JavaScript- handldes adding, visiting, and removig bookmarks
.Dom manipulation - Dynamically creates and updates bookmark cards.
.LocalStorage- can be used to preserve book marks after refreshing the page
